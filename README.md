# HopeMeals agent

Open-source pieces for the Open Agentic Web Challenge:

- `airlock-gate`: an on-device privacy gate for outgoing agent messages, with an extended consent card.
- `nano-provider`: lets the agentic web runtime use Chrome's built-in Gemini Nano for small private steps.
- A partner agentic site (Pune Giving Planner) that talks to the HopeMeals agent.

The HopeMeals site integration itself lives on a branch of the HopeMeals repo, and only the owner deploys it.
